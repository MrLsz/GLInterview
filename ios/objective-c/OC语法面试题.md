# OC 语法面试题

## 一、分类（Category）与类扩展（Extension）的区别

### 题目

Objective-C 中 Category（分类）和 Extension（类扩展）有什么区别？各自适用于什么场景？

### 标准答案

分类和类扩展的区别，我从本质、核心区别、使用场景三个方面来说。

本质上来讲，Category 是在不修改原类的前提下，为已有类追加方法，它编译后运行时把分类里的方法合并到原类的 method list 里，调用时和原类方法没有任何区别；而类扩展本质上是一个匿名分类，只能写在当前类的 .m 文件里，在编译期就和类本身融合。

核心区别有三点：第一，分类不能给类添加成员变量，一定要"存储"属性就得借助关联对象，而类扩展可以正常添加成员变量；第二，分类里的 @property 不会自动生成 getter/setter 和成员变量，扩展里会正常合成；第三，定义位置不同，分类可以写在任意的 .h 或 .m 文件里，扩展只能写在本类的 .m 文件里。

使用场景上，分类主要用于两类：一是对大型类按功能模块拆分，把同一类里不同模块的方法分到多个分类文件里方便维护；二是给系统类或第三方类扩展功能，比如给 NSString 加自定义方法。类扩展主要用于声明私有属性和私有方法、对外隐藏实现，以及做读写权限分离——比如头文件里声明 readonly，在扩展里改成 readwrite，实现对外只读、对内可写。
