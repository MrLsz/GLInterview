# GLInterview

> 面试模拟记录仓库：从 [Glimmer](https://github.com/MrLsz/Glimmer) 知识库随机出题，沉淀题目与标准答案。

## 归档规则

- 一个知识点对应一个大文件，文件内按「一 / 二 / …」累积多道面试题。
- 每个文件只记录「题目」和「标准答案」。
- 分类对齐 Glimmer 知识库（不涉及 HarmonyOS）。

## 分类目录

```
GLInterview/
├── android/                 # Android 开发体系
│   ├── boot/                # 系统架构与启动
│   ├── binder/              # Binder IPC 机制
│   ├── component/           # 四大组件
│   ├── window-input/        # Window 与输入体系
│   ├── view-render/         # View 绘制与渲染
│   ├── build-system/        # 构建与编译体系
│   ├── java/                # Java 语言
│   ├── kotlin/              # Kotlin 语言
│   ├── jvm/                 # JVM 原理
│   └── matrix/              # Matrix APM 源码分析
├── ios/                     # iOS 开发体系
│   ├── objective-c/         # Objective-C 语言
│   ├── swift/               # Swift 语言
│   ├── runtime/             # 语言与运行时
│   ├── foundation/          # 系统底层机制
│   ├── uikit/               # UIKit 框架
│   └── startup/             # 启动与构建
└── ai/                      # AI 开发
    └── python/              # Python / Agent / LLM
```
